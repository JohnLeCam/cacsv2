02 — Données personnelles
Résumé simple : Nous collectons uniquement les données nécessaires au fonctionnement du service. Nous ne vendons aucune donnée. Nous n'utilisons pas de publicité ciblée.

Données collectées via Discord OAuth2

Lorsque tu te connectes avec Discord, nous accédons aux informations suivantes :

  • Identifiant Discord (ID) — pour t'identifier de manière unique
  • Nom d'utilisateur Discord — affiché dans le récapitulatif de commande
  • Avatar Discord — affiché dans la barre de navigation
  • Rôles Discord — pour appliquer les réductions associées à ton rôle

Ces données sont stockées en session (cookie sécurisé) et supprimées à la déconnexion ou après 7 jours d'inactivité.

Données de commande

Lorsque tu passes commande, nous enregistrons :

  • Ton nom d'utilisateur Discord et ton ID
  • Les articles commandés et le montant total
  • La date de la commande
  • L'identifiant du ticket Discord créé

Ces données sont conservées dans notre base de données (Supabase) pour le suivi des commandes. Elles ne sont jamais partagées avec des tiers.

Données de navigation anonymes

Pour afficher le tableau de bord "temps réel" à l'usage exclusif de l'administrateur du site, nous générons un identifiant de session anonyme et temporaire (non lié à ton identité) qui enregistre le contenu de ton panier en mémoire vive sur le serveur. Ces données sont automatiquement supprimées après 2 minutes d'inactivité ou à la fermeture de ta session. Elles ne sont jamais persistées en base de données.

Base légale du traitement (RGPD)

  • Exécution du contrat — données de commande nécessaires à la livraison
  • Intérêt légitime — données de navigation pour le bon fonctionnement du site
  • Consentement — connexion Discord initiée volontairement par l'utilisateur

Sous-traitants

  • Supabase (base de données) — politique de confidentialité
  • Railway (hébergement) — politique de confidentialité
  • Discord (authentification & tickets) — politique de confidentialité
  • Google Fonts (polices d'écriture) — politique de confidentialité

Comment refuser ou supprimer les cookies

Tu peux à tout moment :

  • Vider le panier via le bouton 🗑️ dans le tiroir panier
  • Te déconnecter via le bouton "Déco." — cela supprime le cookie de session
  • Effacer le localStorage depuis ton navigateur : F12 → Application → Local Storage → Effacer
  • Utiliser le mode navigation privée pour éviter tout stockage persistant
